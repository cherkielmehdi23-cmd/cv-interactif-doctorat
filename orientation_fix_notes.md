# Vérification des aperçus académiques corrigés

Le diplôme BTS a été contrôlé après traitement : il est maintenant présenté dans le bon sens de lecture, avec l’en-tête institutionnel et la structure du document visibles horizontalement.

Les zones centrales susceptibles de contenir des identifiants, ainsi que la zone basse contenant les numéros de document, sont masquées dans les copies publiques. La lightbox et les téléchargements publics doivent utiliser ces copies redressées plutôt que les numérisations intégrales.
